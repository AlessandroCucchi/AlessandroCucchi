## 🧭 How I work

| Principle | In practice |
|---|---|
| **Measure against a baseline** | Every model is compared with explicit `DummyClassifier` scores on the same metric |
| **Prevent data leakage** | Duplicates removed before the split, preprocessing inside a `Pipeline`, test set used once |
| **Choose metrics for the domain** | Macro-F1 and per-class recall instead of accuracy on imbalanced data |
| **Check robustness** | Conclusions verified across several random seeds, not one lucky split |
| **State the limits** | Every project documents small samples, uncertainty and what was not tested |
